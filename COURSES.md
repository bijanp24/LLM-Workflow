# Course catalog & authoring

This repository is the **single source of static content** for the
[LLM Academy](https://github.com/bijanp24/LLM-Workflow-Academy). The Academy app
consumes this repo as a git submodule and copies every `*.md` / `*.json` file into
its `/content` root at build time. There is no other content source.

## How content is structured

| Path | Role |
|------|------|
| `catalog.json` | **Master catalog.** Lists every course the Academy shows. Loaded first by the app as `/content/catalog.json`. |
| `course.json` + `docs/` + `quizzes/` + `adapters/` + `README.md` | The **Foundations** course, kept at the repo root for historical reasons. |
| `<course-id>/course.json` + `<course-id>/docs/` + `<course-id>/quizzes/` | Every **other** course, each self-contained in its own folder. |

> **Convention:** Foundations lives at the root; all other courses live in a
> folder named after their `id`. New courses (including ones generated by the
> automation) always use the folder form.

## Catalog schema (`catalog.json`)

```json
{
  "title": "LLM Academy",
  "description": "…",
  "courses": [
    {
      "id": "your-course-id",
      "title": "Your Course Title",
      "description": "Short blurb shown on the catalog page.",
      "manifest": "your-course-id/course.json"
    }
  ]
}
```

`manifest` is the path to the course manifest **relative to the content root**
(i.e. relative to this repo's root).

## Course manifest schema (`<course-id>/course.json`)

```json
{
  "id": "your-course-id",
  "title": "Your Course Title",
  "description": "…",
  "version": "1.0.0",
  "lessons": [
    {
      "id": "lesson-slug",
      "title": "Lesson Title",
      "doc": "your-course-id/docs/01-intro.md",
      "quiz": "your-course-id/quizzes/01-intro.json"
    }
  ]
}
```

Every `doc` and `quiz` path is **relative to the content root** and therefore
**must** be prefixed with the course id folder (e.g. `your-course-id/docs/…`).
`quiz` may be `null` for lessons without an assessment.

## Quiz schema (`<course-id>/quizzes/*.json`)

See `applied-probability/quizzes/01-basics.json` for a complete example.

## Adding a course by hand

1. Create `your-course-id/` with `course.json`, `docs/*.md`, and optional `quizzes/*.json`.
2. Add an entry to `catalog.json`.
3. Open a PR. When it merges, the Academy's submodule pointer is bumped automatically
   and Netlify rebuilds the site with your course.

## Adding a course automatically

The `generate-course` GitHub Action (triggered when an applied repo deploys)
drafts a new course folder and `catalog.json` entry from seed material, then
opens a PR here for review. See `.github/workflows/generate-course.yml`.
